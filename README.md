# Aeternus

Bot Discord completo com economia, jogos, música e painel web.

## Branch `max-immortality`

Esta branch está recebendo o upgrade completo:
- Painel mais fluido e premium
- Jogos mais imersivos e realistas
- Economia e comandos no nível máximo

## Render

- **Root Directory:** deixe **vazio** (raiz do repo)
- **Build:** `npm install`
- **Start:** `npm start` ou `node index.js`
- **Env:** `TOKEN`, `CLIENT_ID`, `CLIENT_SECRET`, `REDIRECT_URI`, `MONGO_URI`, `PORT`

Não use Root Directory `src` — o `package.json` fica na raiz.
