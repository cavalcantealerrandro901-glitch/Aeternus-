# API REST do Aeternus

Se você tem um site, app ou painel próprio, a API permite ler dados de economia e o estado do bot sem depender só de comandos no chat.

## Autenticação

Toda requisição autenticada leva o header:

```http
Authorization: Bearer SEU_TOKEN_AQUI
```

O token é emitido pela equipe do Aeternus. Não publique em repositório público nem em front-end aberto — use só no servidor da sua aplicação.

## Boas práticas

- Trate `401` como token inválido ou expirado.
- Trate `429` como limite de taxa: espere o `Retry-After` antes de tentar de novo.
- Não faça polling agressivo em endpoints de saldo; cacheie por alguns segundos no seu lado.

## O que esperar daqui

A superfície da API cresce conforme o painel e o bot estabilizam novos módulos (drops, loja, guildas). Quando um endpoint novo entrar em produção, esta página ganha o caminho, o método e um exemplo de resposta real — sem placeholder vazio.
