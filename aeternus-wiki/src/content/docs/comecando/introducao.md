# Bem-vindo à wiki do Aeternus

O Aeternus é um bot de Discord com RPG, economia, guildas, jogos e moderação. O prefixo padrão é `O.` — se o admin mudou no painel, use o que o servidor definiu.

## Em cinco minutos

1. **Personagem** — `O.j criar` (nome, classe; foto opcional no PV do bot).
2. **Perfil** — `O.j perfil` para ver nível, XP, éter e guilda.
3. **Daily** — `O.daily` uma vez por dia.
4. **Ajuda** — `O.ajuda` lista categorias; `O.ajuda nome` explica um comando.

## O que existe de verdade no bot

| Área | Para que serve |
| --- | --- |
| RPG | Classes, habilidades, arena e masmorra |
| Economia | Éter, cristais, banco, daily, loja |
| Guildas | Clã, baú, cargo-tag, ranking |
| Jogos | Minas, blackjack e outros com aposta |
| Moderação | Anti-spam, ban, mute, warns |
